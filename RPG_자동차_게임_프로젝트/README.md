# RPG 자동차 주차·도로주행 게임

## 실행
```bash
pip install -r requirements.txt
streamlit run main.py
```

## 이번 수정
- 메인 화면에서 게임 모드 선택
- 메인 화면에서 자동차 선택 및 구매
- 흰색 배경
- 도로는 중앙선과 양쪽 끝 라인만 표시
- 도로와 배경은 고정
- 자동차가 화면 안에서 직접 이동
- 방향키 기반 전진/후진/조향
- Space로 1인칭/3인칭 시점 전환
- 결과 화면에서 주행 시간, 충돌, 방향, 획득 금액 표시

현재 버전은 게임 구조를 잡기 위한 프로토타입입니다
