# RPG 자동차 주차게임

이번 버전은 주차만 남긴 프로토타입입니다

## 변경사항
- 자유주행 삭제
- 운전면허시험 삭제
- 게임 모드 선택 없이 바로 주차 시작
- 전면주차 / 후진주차 / 평행주차 / 직각주차 중 하나가 랜덤으로 등장
- 주차 유형에 따라 주차장 장면이 변경됨
- 주차라인을 실제 게임 화면에 표시
- 주차라인 양옆에 다른 차량 배치
- 배경은 한 장면 안에서는 고정되어 스크롤되지 않음
- 자동차는 화면 안에서 직접 이동
- 주차 시간, 충돌, 위치 오차, 각도 오차, 정확도 측정
- 자동차 구매 및 RPG 돈 시스템 유지

## 실행
```bash
pip install -r requirements.txt
streamlit run main.py
```


## 자동 종료/벌금 시스템
- 차량이 주차 칸 안에 들어가고 거의 정지하면 자동으로 주차 완료
- 기존에 주차된 차량과 접촉하면 즉시 종료
- 접촉 시 100원 벌금
- 보유금액이 100원보다 적으면 부족한 금액만큼 부채가 생김
- 이후 주차 성공으로 돈을 벌면 벌어들인 돈으로 부채가 자동 상환됨
